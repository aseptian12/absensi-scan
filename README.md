# Sistem Absensi Siswa Barcode v3.0

Frontend statis (HTML/CSS/JS) untuk GitHub Pages, dengan Google Apps Script sebagai REST API.

- `index.html` · `css/style.css` · `js/config.js` (isi `GAS_URL`) · `js/api.js` · `js/app.js`
- Backend (`Kode.gs`, `appsscript.json`) diberikan terpisah — jangan di-push ke repo ini.

Langkah lengkap ada di **PANDUAN-INSTALASI.md**.
